# 📱 Clothing Store Mobile App (Expo Go)

แอปพลิเคชันมือถือสำหรับร้านค้าเสื้อผ้าออนไลน์ เชื่อมต่อฐานข้อมูลและระบบหลังบ้าน PHP/MySQL ผ่าน REST API รองรับการรันและทดสอบสดบนมือถือผ่าน **Expo Go**

---

## 🌟 ฟังก์ชันการทำงานในแอปมือถือ

1. **ฝั่งลูกค้า (Customer)**:
   - 👕 ดูแคตตาล็อกสินค้า ค้นหา และกรองตามหมวดหมู่ (ผู้ชาย, ผู้หญิง, Clearance Sale)
   - 🔍 ดูรายละเอียดสินค้า เลือกขนาด (S, M, L, XL, 2XL) และเลือกจำนวน
   - 🛒 ระบบตะกร้าสินค้า ปรับจำนวนสินค้า และคำนวณยอดเงินแบบเรียลไทม์
   - 💳 **ชำระเงินด้วย PromptPay QR Code**:
     - แสดงรูป QR Code พร้อมเพย์
     - **กดเลือกรูปสลิปจากอัลบั้มในโทรศัพท์มือถือ** เพื่อแนบเป็นหลักฐาน
     - ส่งคำสั่งซื้อและรูปสลิปเข้าเซิร์ฟเวอร์ PHP สถานะเริ่มต้นเป็น `Pending`
   - 📦 **ประวัติคำสั่งซื้อ**: ติดตามสถานะออเดอร์ (Pending / Paid) และกดดูรูปสลิปที่แนบไปได้

2. **ฝั่งผู้ดูแลระบบ (Admin)**:
   - 👑 เมื่อล็อกอินด้วยบัญชีแอดมิน จะมีปุ่ม **"⚡ แผงจัดการออเดอร์ & ตรวจสลิป (Admin)"**
   - 📊 การ์ดสรุป KPI (ออเดอร์ทั้งหมด, รอตรวจสลิป, ยอดขายสุทธิ)
   - 🔍 **ระบบตรวจสอบสลิป**: กดดูรูปสลิปขนาดเต็มที่ลูกค้าส่งมาจากมือถือ
   - ✅ **อนุมัติการชำระเงินใน 1 คลิก**: กดปุ่ม "อนุมัติสลิป (Paid)" เพื่อปรับสถานะเป็น `Paid` ทันที

## ⚙️ การตั้งค่า IP Address

ก่อนรันแอป ให้ตรวจสอบว่าโทรศัพท์มือถือและคอมพิวเตอร์เชื่อมต่อ **Wi-Fi วงเดียวกัน**:

เปิดไฟล์ [`mobile/src/config.js`](file:///D:/Xamp/htdocs/clothing_store/mobile/src/config.js) และตั้งค่า IP ของคอมพิวเตอร์:
```javascript
export const SERVER_IP = '192.168.1.141'; // เปลี่ยนเป็น IP ของเครื่องคุณ (ดูได้จาก ipconfig)
```

## 🚀 วิธีการรันแอปบนมือถือผ่าน Expo Go

### ขั้นตอนที่ 1: ติดตั้งแอป Expo Go บนมือถือ
- **Android**: ดาวน์โหลดจาก [Google Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent) (ค้นหา "Expo Go")
- **iOS**: ดาวน์โหลดจาก [App Store](https://apps.apple.com/app/expo-go/id982107779) (ค้นหา "Expo Go")

### ขั้นตอนที่ 2: รันเซิร์ฟเวอร์ Expo ในคอมพิวเตอร์
เปิด Terminal หรือ PowerShell แล้วเข้าไปที่โฟลเดอร์ `mobile`:

```bash
cd D:\Xamp\htdocs\clothing_store\mobile
npx expo start
```

### ขั้นตอนที่ 3: สแกนเพื่อเปิดแอปบนมือถือ
- **บน Android**: เปิดแอป Expo Go แล้วกด **"Scan QR code"** สแกน QR Code ที่แสดงใน Terminal
- **บน iPhone (iOS)**: เปิดแอป **กล้องถ่ายรูป (Camera)** ของเครื่อง สแกน QR Code แล้วกดเปิดในแอป Expo Go
